# About Aelin

Aelin 是一个面向持续工作的 **AI workspace**。

Aelin 把一个主题相关的聊天、文件、网页研究、workspace memory 和 desktop capabilities 放进同一个 workspace，让工作可以在时间里持续推进。

## What Aelin Is

Aelin 把这些能力组织在同一个 workspace：

- Chat
- Files
- Web research
- Workspace memory
- Desktop capabilities

Aelin 的产品重点是让同一个主题始终留在可继续工作的状态里。

## What It Is For

Aelin 最适合下面这些工作方式：

- 围绕同一主题持续研究
- 在聊天里处理附件、笔记和网页信息
- 让历史结论在后续工作里继续可用
- 从 Web 开始，再在需要时延伸到 Desktop

## Product Principles

### Workspace first

关键上下文、文件和结论都留在 workspace 里，方便后续继续使用。

### Answer first

先给可以继续使用的结果，再补充依据、限制和下一步。

### Clear boundaries

网页研究、文件、记忆和桌面能力各自承担不同职责，方便用户理解系统在做什么。

### Surfaces that connect

Web 和 Desktop 是同一个 workspace 的两个入口。
