# About Aelin

Aelin 是一个面向持续工作的 **AI workspace**。

它适合那些不会在一轮聊天里结束的任务。

如果一个主题需要：

- 持续多天甚至更久
- 反复读取附件和外部资料
- 保留之前的判断和上下文
- 在需要时延伸到桌面环境

Aelin 就会比一次性的聊天工具更合适。

## What Aelin Is

Aelin 把这些能力放进同一个 workspace：

- Chat
- Files
- Web research
- Workspace memory
- Desktop capabilities

目标很直接：让同一个主题可以在时间里继续推进，而不是每次重新开始。

## What It Is For

Aelin 最适合下面这些工作方式：

- 围绕同一主题持续研究
- 在聊天里处理附件、笔记和网页信息
- 让历史结论在后续工作里继续可用
- 从 Web 开始，再在需要时延伸到 Desktop

## Product Principles

### Workspace first

重要内容应该留在 workspace 里，而不是散落在一次次独立对话中。

### Answer first

先给可以继续使用的结果，再补充依据、限制和下一步。

### Clear boundaries

网页研究、文件、记忆和桌面能力各自承担不同职责，方便用户理解系统在做什么。

### Surfaces that connect

Web 和 Desktop 不是两套割裂的体验，而是同一个工作流的不同入口。
