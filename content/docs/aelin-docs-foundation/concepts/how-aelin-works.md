# How Aelin Works

Aelin 的工作方式可以概括成四步：

1. 理解你的目标
2. 收集当前需要的上下文
3. 组织回答与行动
4. 把重要信息留在工作区

## 1. 理解你的目标

当你提出一个问题时，Aelin 首先会判断：

- 你想得到一个答案，还是想推进一个任务
- 当前问题更依赖历史上下文，还是更依赖外部信息
- 是否需要读取附件、工作区记忆或网页信息

这一步的目的，是让 AI 不只是“接一句话”，而是真正理解你现在要完成什么。

## 2. 收集当前需要的上下文

Aelin 会围绕当前任务组织可用信息来源，例如：

- 当前会话
- 工作区记忆
- 你上传的附件
- 外部网页信息

这样做的意义是，把问题放回真实背景里处理，而不是孤立地回答一句话。

## 3. 组织回答与行动

回答不只是“给一句结论”，还可能包括：

- 更清晰的解释
- 可继续推进的下一步
- 与附件或资料相关的提炼结果
- 在桌面环境里可继续执行的动作

对用户来说，最重要的是：Aelin 希望帮助你把任务继续做下去，而不是只停留在一轮对话里。

## 4. 把重要信息留在工作区

当某些信息对后续工作有长期价值时，Aelin 会把它们留在工作区语境里。

这让你下次回来时，可以继续围绕同一主题工作，而不需要重新搭建全部背景。

## 为什么这种方式适合长期工作

这种工作方式更适合持续性的主题，因为它能把几个关键环节连在一起：

- 问题可以在原有上下文上继续推进
- 附件、网页信息和历史结论可以一起参与当前任务
- 重要信息能够沉淀到 workspace，方便下次继续

对用户来说，这意味着 Aelin 不只是给出一轮回答，而是在帮助你把同一件事稳定地做下去。
