# Agent Chat

## 让对话真正进入工作流

Aelin 的聊天体验强调连续任务、上下文承接和协作感，让对话真正成为工作流的一部分。

你在使用时会感受到几件事：

- 对话可以持续推进同一主题
- 附件与资料能自然进入上下文
- 回答通常会带着下一步建议
- 任务状态和执行过程不会完全消失在黑盒里

## Answer-first

Aelin 的默认风格是先给你一个可以继续使用的结果，再补充：

- 关键依据
- 可继续推进的方向
- 与资料、附件或桌面任务相关的下一步

## 为什么它适合连续任务

### 会话不是孤立的

同一个 workspace 里的历史上下文能帮助后续对话继续推进。

### 资料不是外挂

附件、文档和已有结论可以和问题一起进入工作流，而不是每次单独处理。

### 执行感更强

当任务涉及工具、资料或后续动作时，Aelin 不只是“说完就结束”，而是尽量把过程组织得更可感知。

## 最适合的使用方式

Aelin 最适合这样的聊天：

- 你已经在围绕一个主题持续工作
- 你希望 AI 记住重要上下文
- 你希望资料、记忆和后续动作在同一个地方发生

如果你只是偶尔做一次性的轻量问答，它也能回答；但当问题需要连续推进时，Aelin 的优势会更明显。
