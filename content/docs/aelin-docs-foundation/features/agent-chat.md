# Agent Chat

Agent Chat 是你使用 Aelin 的主要入口。

它不是为了把界面做成“更像聊天应用”，而是为了把对话真正接到一个持续工作的 workspace 上。

## What It Does

- 让同一主题的对话持续推进
- 让文件和资料进入当前任务
- 让重要上下文留在 workspace
- 让回答更接近“可继续工作”的结果

## Best For

Agent Chat 特别适合这些任务：

- 持续研究某个主题
- 一边看文件，一边推进问题
- 基于历史结论继续追问
- 需要明确下一步而不是只要一段解释

## What to Expect

Aelin 的默认风格更接近 answer-first：

- 先给你一个可使用的结果
- 再补充判断依据
- 再指出可以继续推进的方向

如果当前任务涉及文件、网页研究或 Desktop 能力，这些内容也会围绕同一个 workspace 组织起来。

## Works Best When

- 你愿意把一个主题留在固定 workspace 中
- 你希望文件、结论和新问题在同一个地方发生
- 你更关心持续推进，而不是一次性漂亮回答
