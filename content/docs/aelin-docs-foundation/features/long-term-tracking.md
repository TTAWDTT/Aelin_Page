# Long-term Tracking

## 让一个主题真正活下来

Aelin 的长期价值，在于让同一个主题可以在时间里持续存在：

- 资料会继续留在工作区里
- 结论可以反复复用
- 下一次回来时，可以直接接着做

这意味着你不用每次都重新解释背景、重新上传资料、重新整理上下文。

## 它适合什么样的主题

长期追踪特别适合这些场景：

- 长期研究一个项目或方向
- 跟进一个持续变化的对象
- 持续沉淀某个领域的资料和结论
- 把一个想法从最初问题一路推进到可执行结果

## Aelin 如何帮助你持续推进

### 工作区承载上下文

一个主题的资料、问题和结论可以放在同一个 workspace 里，后续工作不容易断。

### 记忆承载重要信息

真正有价值的内容可以沉淀下来，为后续对话继续提供背景。

### 对话承载推进过程

你不需要每次都重新开始，只需要围绕同一主题继续追问、修正和扩展。

## 对用户最大的意义

长期追踪不是“让 AI 自动盯着一切”，而是让一个主题能在你的工作流里持续存在。

对很多人来说，这比一次性的漂亮回答更重要。
