# Proactive Interaction

在 Aelin 里，proactive interaction 的重点不是“自动替你做决定”，而是帮助你在回答之后更容易继续工作。

## What It Looks Like

- 给出下一步建议
- 指出还缺什么信息
- 帮你把一个主题组织成可继续推进的状态
- 让 workspace 在你回来时仍然有上下文

## Best For

- 一个主题已经有明确上下文，适合继续推进
- 某个任务已经完成一部分，需要下一步建议
- 某个对象值得后续继续关注

## What It Is Not

这不是“全自动代办系统”。

Aelin 仍然应该是：

- 可理解的
- 可控制的
- 由用户掌握节奏的

## Why It Matters

很多 AI 工具的问题在于：回答结束，任务也跟着结束。

而 Aelin 想做的是让“回答之后还能做什么”也成为产品体验的一部分。
