# Proactive Interaction

在 Aelin 里，proactive interaction 会让回答之后的下一步更加清晰。

## What It Looks Like

- 给出下一步建议
- 指出还缺什么信息
- 帮你把一个主题组织成可继续推进的状态
- 让 workspace 在你回来时仍然有上下文

## Best For

- 一个主题已经有明确上下文，适合继续推进
- 某个任务已经完成一部分，需要下一步建议
- 某个对象值得后续继续关注

## How It Stays Useful

Aelin 会把这类帮助保持在可理解、可控制的范围里：

- 可理解的
- 可控制的
- 由用户掌握节奏的

## Why It Matters

任务推进通常发生在第一次回答之后。

Proactive Interaction 会让 Aelin 在这个阶段继续提供帮助，让用户更容易决定下一步、补足缺失信息并保持节奏。
