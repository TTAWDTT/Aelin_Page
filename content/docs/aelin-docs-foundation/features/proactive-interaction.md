# Proactive Interaction

## 不只回答，还帮助你继续推进

Aelin 的主动能力，重点不是“替你做决定”，而是：

- 提醒你什么值得继续跟进
- 帮你看到下一步能做什么
- 让一个主题不会在回答结束后立刻失去延续性

## 主动体验应该是什么样

对用户来说，好的主动体验应该具备三个特点：

- 有帮助
- 可理解
- 可控制

也就是说，Aelin 的主动性应该像一个靠谱的工作搭档，而不是一个随时打断你的系统。

## 它最适合哪些场景

- 一个主题已经有明确上下文，适合继续推进
- 某个任务已经完成一部分，需要下一步建议
- 某个对象值得后续继续关注

## 为什么这件事重要

很多 AI 产品的问题在于：回答结束，任务也就结束了。

Aelin 希望把“回答之后还能做什么”也纳入产品体验里，让工作流真正连续起来。
