# Web Search + Local Memory

Aelin 会同时使用两类上下文：

- web search
- workspace memory

它们承担的职责不同。

## When Web Search Matters

当问题依赖下面这些内容时，web search 更重要：

- 最新变化
- 外部证据
- 当前 workspace 里还没有的信息
- 需要核对来源的资料

## When Workspace Memory Matters

当问题依赖下面这些内容时，workspace memory 更重要：

- 你已经做过的研究
- 之前沉淀下来的判断
- 当前主题的长期上下文
- 你不想每次重复解释的背景

## What This Gives You

把两者放在一起，你可以同时得到：

- 既知道你在做什么
- 也知道外面的信息发生了什么

这会直接减少三种成本：

- 重复解释背景的成本
- 在多个工具间切换的成本
- 追踪“哪些信息是新的，哪些是旧的”的成本
