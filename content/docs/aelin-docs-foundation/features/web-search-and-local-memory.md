# Web Search + Local Memory

## 两种能力，两个职责

Aelin 会同时使用：

- **网页信息**
- **工作区记忆**

但它们并不是同一件事。

## 网页信息负责“新”

当问题依赖：

- 最新变化
- 外部证据
- 当前工作区里还没有的信息

网页信息会特别重要。

这适合用来处理：

- 新闻与公告
- 产品更新
- 新出现的资料
- 需要核对来源的内容

## 工作区记忆负责“连续”

当问题依赖：

- 你已经研究过的主题
- 之前沉淀下来的结论
- 当前 workspace 的长期上下文

工作区记忆就会更重要。

这让 Aelin 能够在后续会话里继续利用你已经建立好的背景，而不是每次从零开始。

## 为什么要把两者结合

如果只有网页信息，系统会缺少连续性。

如果只有工作区记忆，系统又会缺少对外部变化的感知。

把两者放在一起，Aelin 才更像一个真实的工作搭档：

- 既知道你在做什么
- 也知道外面的信息发生了什么

## 对用户最直接的好处

你不需要在“长期上下文”和“最新信息”之间二选一。

Aelin 的目标是同时给你：

- 连续性
- 新鲜度
- 更少的重复解释成本
