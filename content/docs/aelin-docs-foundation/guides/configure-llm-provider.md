# Configure LLM Provider

## 为什么 Aelin 允许你自己选模型

不同用户的需求并不一样。

有人更看重：

- 推理质量
- 成本
- 响应速度
- 自定义网关
- 与现有平台的兼容性

Aelin 允许你自己配置模型服务，就是为了让产品更容易融入你已有的工作环境。

## 常见配置项

- `provider`
- `model`
- `base_url`
- `api_key`

## 配置建议

### 先跑通一条最小闭环

与其一开始配置很多模型，不如先确认一套最小可用组合：

1. 一个 provider
2. 一个 model
3. 一个可用的 base URL
4. 一把有效的 API key

### 按场景选择模型

如果你常做：

- 深度推理任务
- 大量资料阅读
- 持续性的复杂主题

可以优先选择更稳定、更擅长长上下文的模型。

如果你常做：

- 高频轻量提问
- 快速整理资料
- 成本敏感型工作流

可以优先选择响应更快、成本更低的组合。

## 对用户最重要的一点

模型配置决定的是 Aelin 用什么“大脑”来工作，但 Aelin 的价值并不只来自模型本身。

真正让体验不同的，是模型与这些能力一起协作：

- 工作区记忆
- 附件理解
- 网页信息
- 桌面环境
