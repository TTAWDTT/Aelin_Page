# Run on Web / Desktop / Mobile

## Which Surface Should You Choose?

大多数用户的选择可以很简单：

- 想快速开始：用 Web
- 需要本地能力：用 Desktop
- 只是轻量访问：可以看 Mobile

## Web

Web 是最直接的入口。

它适合：

- 开始新的对话
- 浏览文档
- 配置模型
- 处理大多数 workspace 任务

## Desktop

Desktop 更适合任务已经离开浏览器的时候。

它特别适合：

- 需要本地能力的任务
- 需要把聊天继续带到桌面的场景
- 希望 AI 更贴近真实工作环境的用户

## Mobile

移动端更适合轻量访问。

如果你要完整体验 Aelin 的工作流能力，今天更推荐从 Web 或 Desktop 开始。

## Recommended Path

对多数用户来说，最自然的路径是：

1. 先在 Web 里建立 workspace
2. 在需要本地能力时切到 Desktop
