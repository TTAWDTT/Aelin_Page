# Run on Web / Desktop / Mobile

## Web

Web 是进入 Aelin 最直接的方式。

它适合：

- 开始新的对话
- 浏览文档
- 配置模型
- 处理大多数基于 workspace 的任务

## Desktop

Desktop 让 Aelin 更接近真实工作环境。

它特别适合：

- 需要本地能力的任务
- 需要把聊天继续带到桌面的场景
- 希望 AI 与本地工作流更紧密连接的用户

## Mobile

移动端可以承接轻量访问，但如果你希望完整体验 Aelin 的工作流能力，今天更推荐从 Web 或 Desktop 开始。

## 如何选择

如果你想：

- 先快速体验 Aelin
  - 从 Web 开始
- 连接本地环境和桌面能力
  - 使用 Desktop

对多数用户来说，最自然的路径也是：

- 先在 Web 里建立 workspace
- 再在需要时把任务延伸到 Desktop
