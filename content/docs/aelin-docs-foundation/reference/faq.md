# FAQ

## Aelin 和普通聊天工具有什么不同

Aelin 更强调持续工作。

它把对话、工作区记忆、网页信息、附件和桌面能力放进同一个 workspace，让你可以围绕同一主题不断推进。

## Aelin 每次都会搜索网页吗

不一定。

当问题需要最新信息或外部证据时，网页信息会更重要；当问题依赖工作区上下文时，记忆和已有资料会更重要。

## Aelin 会记住我之前做过的事情吗

Aelin 会利用工作区里的记忆和资料，帮助后续任务继续推进。

它的重点不是“神秘地记住一切”，而是让重要信息在 workspace 里持续可用。

## 我可以上传附件吗

可以。

附件是 Aelin 工作流的一部分，而不是额外的外挂功能。

## 我可以使用自己的模型服务吗

可以。

你可以配置：

- provider
- model
- base URL
- API key

## Web 和 Desktop 有什么区别

Web 更适合快速开始和主要聊天体验。

Desktop 更适合需要本地能力、桌面协同和更深工作流连接的场景。

## Aelin 最适合拿来做什么

最适合这些场景：

- 持续研究一个主题
- 结合附件和网页信息推进任务
- 在同一个 workspace 里积累长期上下文
- 让 AI 真正进入你的工作流
