# Known Issues

## 1. 文件语义与本地执行语义还没有完全统一

这是当前系统里最值得持续关注的边界之一。

在混合运行场景下：

- DeepAgents 的文件工具
- Aelin 的桌面执行桥

并不总是处在同一个“文件世界”里。

这会影响你对这些问题的判断：

- 某个文件到底写到了哪里
- 某个执行动作是否真的看得见前一步产物
- 某个 artifact 是否能被自然回收到前端

## 2. 桌面能力依赖运行环境

设备与本地执行能力并不是纯 Web 默认就能使用的。

它依赖于：

- desktop runtime 是否存在
- 本地桥是否可用
- 当前平台是否允许

## 3. Web 与 Desktop 的体验深度仍有差异

当前主维护表面是 Web 与 Desktop，但两者提供的能力深度并不完全一致。

Web 更偏展示与聊天，Desktop 更偏本地接入。

## 4. 某些产品残留仍在清理中

随着 Aelin 持续从旧原型收敛到当前 native-shell 方向，仓库里仍可能存在：

- 旧命名残留
- 旧菜单入口残留
- 旧文档措辞残留

这类内容会逐步清理，但在快速迭代阶段不一定一次性消失。

## 5. 文档有时会晚于代码

当前版本的 Aelin 变化速度仍然较快。

如果你发现：

- 文档说法
- 页面表现
- 当前实现

三者之间有轻微差异，请优先以当前主线实现与架构文档为准，再回头修正文档。
