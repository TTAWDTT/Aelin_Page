# Known Issues

## 1. Some capabilities are Desktop-only

如果你使用的是纯 Web 环境，一些与本地设备或桌面协同相关的能力不会完整出现。

## 2. File and execution boundaries still matter

当任务同时涉及工作区文件、附件和桌面执行时，产物的落点和展示方式有时需要特别确认。

## 3. Surface differences are expected

Web 和 Desktop 面向的使用深度并不完全相同，因此在某些能力上会存在差异。

## 4. Docs will keep moving with the product

Aelin 仍在快速迭代中，文档会持续跟进新的能力与产品整理。
