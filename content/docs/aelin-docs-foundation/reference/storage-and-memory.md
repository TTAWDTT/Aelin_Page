# Storage and Memory

## What Gets Stored at the Workspace Level

在 Aelin 里，一个 workspace 不只是聊天列表。

它还可以承接：

- 长期上下文
- 相关文件和资料
- 有价值的结论
- 后续继续工作的基础

## What Memory Is For

workspace memory 会保留真正重要的背景，让后续任务可以直接复用。

它最适合保存：

- 一个主题的长期背景
- 后续任务可复用的判断
- 不想在每轮对话里重复解释的内容

## How Files Fit In

文件不会脱离 workspace 单独存在。

它们会和：

- 当前问题
- workspace memory
- 后续结论

共同组成一个可继续推进的工作流。

## What This Means for the User

对用户来说，最直接的结果是：

下次回来时，Aelin 仍然知道你在做什么，并能继续利用已有背景、文件和结论。
