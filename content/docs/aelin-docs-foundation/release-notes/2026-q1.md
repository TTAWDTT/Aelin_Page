# Release Notes 2026 Q1

这份 release note 记录的重点，不是某个单独页面的小改动，而是 Aelin 整体方向的变化。

## 这一个阶段最大的变化

Aelin 正式从“自定义聊天原型”收敛到“DeepAgents-native 薄产品壳”。

这句话背后的实际含义包括：

- 聊天主链以官方 Agent Server 为准
- 前端以官方 run metadata 为准
- DeepAgents graph 成为真正的 agent 执行核心
- Aelin 自己保留产品 API、附件、设备与桌面边界

## 具体体现

### 官方 thread / run 成为主链

当前聊天主入口围绕：

- `assistants`
- `threads`
- `runs/stream`

组织，而不是围绕旧自定义流协议。

### 记忆锚点切得更清楚

当前主链记忆锚定在工作区级 `/memory/AGENTS.md`，而不是把多种历史上下文混成难以解释的一团。

### 前端执行态更接近真实运行时

执行面板与工具状态开始更多来自：

- tools
- subagents
- values
- messages

而不是从回答文本里逆向猜测。

### 官网文档同步刷新

本阶段也同步重写了官网文档，使对外说明不再停留在旧版本的叙事里。

## 当前仍在继续推进的边界

- 文件世界与本地执行世界的进一步统一
- 产物回收到前端展示的持续优化
- 旧命名与旧产品残留的继续收敛

## 总结

如果要用一句话总结这一阶段：

> Aelin 现在更像一个真正的 agent product shell，而不是一个围绕自定义聊天协议堆出来的原型。
