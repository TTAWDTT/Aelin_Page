# Release Notes 2026 Q1

这一阶段，Aelin 的产品重点集中在三件事上：

## 1. 更清晰的产品表达

官网与文档内容被重新整理，让用户更容易理解：

- Aelin 是什么
- 它适合什么场景
- 为什么它更适合持续工作的主题

## 2. 更连贯的 workspace 体验

Aelin 继续强化：

- 对话与上下文的连续性
- 资料与附件的协同
- 长期记忆在工作流中的作用

## 3. 更完整的 Web 与 Desktop 结合

Web 负责更轻量、更直接的入口体验；Desktop 则继续承接更深的本地协同能力。

## 总结

这个阶段的目标很明确：

让 Aelin 从“能回答问题”进一步走向“能陪用户把事情持续做下去”。
