# Release Notes 2026 Q1

## Highlights

- 首页和文档入口已经重写为更清晰的产品导航结构。
- 核心页面现在按 Start Here、By Goal、Learning Path 组织。
- 功能页、指南页和参考页采用了更统一的产品文档写法。

## Documentation Updates

### Homepage

- 首页现在直接回答 Aelin 是什么、适合谁，以及用户接下来应该读什么。
- 主要内容改成 Start Here、Core Capabilities 和 Learning Path。

### Docs Root

- 文档首页现在提供 Start Here、By Goal、Recommended Path 和 Need a Fast Answer。
- 入口设计更适合第一次接触 Aelin 的用户快速定位信息。

### Core Pages

- 多数页面统一成 What It Does、Best For、What to Expect、Read Next 这类结构。
- 页面内容更偏向任务说明和导航，整体更简洁、更便于查阅。

## Product Direction

- Aelin 继续围绕 workspace-first 的产品方向组织能力。
- 聊天、文件、网页研究、记忆和桌面能力会作为同一工作流的一部分呈现给用户。
- Web 和 Desktop 会继续作为同一个 workspace 的两个入口发展。
